**3)**The process happens in these steps:



1. The user enters a website address, such as www.example.com.
2. The browser sends a request to the web server.
3. The server receives the request.
4. The server processes the request.
5. The server sends files such as HTML, CSS and JavaScript back to the browser.
6. The browser reads and interprets the HTML.
7. CSS is used to style the page.
8. JavaScript adds functionality and interaction.
9. The browser renders the final webpage on the screen.

**6)Frontend Developer**



Responsible for the user interface.



Tasks:



Creates webpages.

Designs buttons, forms and menus.

Makes websites responsive.

Uses HTML, CSS and JavaScript.



Example: Creating the Amazon shopping cart interface.



**Backend Developer**



Responsible for server-side logic.



Tasks:



Creates APIs.

Handles user authentication.

Processes requests.

Connects the application to databases.



Example: Checking whether a username and password are correct.



**Database Administrator (DBA)**



Responsible for managing databases.



Tasks:



Creates and manages databases.

Stores and retrieves data.

Maintains database security.

Creates backups.

Manages database performance.



Example: Managing customer and order information in an e-commerce application.

Different rendering engines may interpret certain HTML/CSS features differently, which can sometimes cause a website to look or behave slightly differently across browsers.
